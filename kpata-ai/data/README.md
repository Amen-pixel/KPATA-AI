# Données

- `briefs/` : annonces d'exemple annotées (JSON). Versionnées dans Git.
- `audio/` : enregistrements. **Ignorés par Git.** Dossier partagé de l'équipe : à compléter (lien Drive).
  Nommage proposé : `<langue>_<locuteur>_<numéro>.wav`, par exemple `yoruba_L03_012.wav`
  (langue en minuscules, identifiant du locuteur anonymisé, numéro de la note vocale).
- `tableau_reference/` : tableau de référence du jeu de données (Phase 1).

Ne jamais écrire le vrai nom ou le numéro d'un locuteur dans un nom de fichier.
